# Pre-existing Work Disclosure

ShiftZero is a new project and codebase created for the All Things Agentic Hackathon beginning on 2026-08-08.

The author has prior professional and personal experience with AGV fleet management, industrial control, physical AI, and security systems, including concepts associated with FleetCtrl and SuperFirewall. That experience informed terminology, failure modes, threat modeling, and product judgment. No pre-existing source repository, proprietary code, customer data, industrial configuration, model weights, visual assets, or renamed product implementation was copied into ShiftZero.

The following were created specifically for this project:

- Deterministic nine-AGV digital twin and scenario suite
- ActionProposal, ActionTicket, ExecutionResult, policy, and trace contracts
- Google ADK Agent Fleet definitions and tools
- FastAPI runtime, SSE/read-model API, and Cloud evidence adapters
- ShiftZero Command Center design and implementation
- Competition architecture, documentation, evaluation set, and demo materials

Open-source dependencies are used under their respective licenses and are declared in the lockfiles and requirements files.
