## Description

ShiftZero is a governed autonomous factory-operations agent fleet built for the All Things Agentic Hackathon — Fortified Enterprise Fleet track.

One objective drives a nine-AGV digital twin: move 42 pallets before the deadline while preserving a 25% battery reserve. Gemini 3.5 Flash on Vertex AI and five Google ADK agents plan, dispatch, recover, and screen untrusted input. A deterministic Safety Kernel retains execution authority through identity checks, exact schemas, state freshness, route and battery policy, idempotency, and single-use Action Tickets.

This 3:56 live demonstration covers an AGV03 blocked-route recovery, AGV07 at a 21% battery reserve breach, a prompt-injection defense that issues no ActionTicket, incident trace evidence, and the verified 42/42 outcome with three recoveries and zero safety violations. The same recording then shows the deployed Cloud Run metrics and logs, Firestore data, and Cloud Trace evidence.
